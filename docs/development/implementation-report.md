# 바로발행 구현 보고서

## 구현 결과

- **REQ-001~003:** 글 묶음 입력과 `구분선 → 글 번호 → 반복 H1 → 단일 글` 우선순위 분리를 구현했다.
- **REQ-004~006:** 제목 추출, 공백·문단 정리, 제목·목록·인용·링크·코드 Markdown 변환을 구현했다.
- **REQ-007~008:** Markdown 표의 정렬 표시를 읽고 표 제목행 색상 프리셋을 인라인 스타일로 직렬화했다.
- **REQ-009~011:** 글별 제목·글자 수·표 개수·미리보기와 제목/안전/서식 복사를 구현했다. 리치 클립보드 실패 시 일반 텍스트로 대체한다.
- **REQ-012~014:** 네트워크·저장소 없이 브라우저 메모리에서만 동작하며, 입력 HTML은 실행하지 않고 텍스트로 이스케이프한다.
- **REQ-015~017:** 권장 글 수 안내, 반응형 화면, 빈 입력·100,000자 초과 검증을 구현했다.
- **DEV-007:** `format_blog_articles` WebMCP 도구가 화면과 같은 변환 상태를 사용하도록 연결했다.
- 대량 줄 입력은 6,000줄, 결과는 50편으로 제한하고 분리 경로를 선형 처리해 메인 스레드 정지 위험을 줄였다.
- 불규칙한 표의 초과 셀과 일반 역슬래시, 코드 블록 빈 줄, 비연속 번호 목록을 보존한다.
- React 계열 런타임을 보안 수정 버전 19.2.8로 통일했다.

## 핵심 구현 선택

1. 네이버가 외부 HTML 서식 보존을 보장하지 않으므로 안전 복사와 서식 복사를 분리했다.
2. 원문 HTML을 허용 목록으로 정화하는 대신 처음부터 모두 이스케이프해 실행 가능한 태그가 만들어지지 않게 했다.
3. 분리 근거가 부족한 원고는 임의로 자르지 않고 한 편으로 유지한다.
4. 한국어 문법 교정은 외부 API 없이 정확도를 보장할 수 없어, MVP에서는 중복·특수 공백과 문단 경계만 정리한다.
5. 이미지는 복사하지 않고 네이버 포토 업로더 별도 사용을 안내한다.

## 범위 밖

- 네이버 로그인과 자동 발행
- 이미지 복사·업로드
- 외부 AI 또는 맞춤법 API를 사용한 문법 교정
- 계정 간 원고 동기화와 영구 저장
