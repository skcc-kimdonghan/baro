# 바로발행 개발 계획

## 제품 목표

GPT에서 작성한 3~5개 글 묶음을 브라우저 안에서 글별로 분리하고, 네이버 블로그에 붙여넣기 좋은 문단·목록·표 형식으로 정리한 뒤 각 글을 따로 복사할 수 있게 한다.

네이버는 외부 HTML 서식의 완전한 보존을 보장하지 않으므로 두 가지 복사 방식을 제공한다.

- **안전 복사:** 정돈된 일반 텍스트를 복사한다.
- **서식 복사(실험):** `text/html`과 `text/plain`을 함께 기록해 제목, 목록, 표, 표 제목행 색상을 최대한 유지한다.

모든 변환은 브라우저 메모리에서만 수행한다. 네이버 로그인, 자동 발행, 이미지 업로드, 외부 AI 교정은 MVP 범위에 포함하지 않는다.

## 요구사항

- **REQ-001:** 여러 글을 한 입력창에 붙여넣을 수 있다.
- **REQ-002:** 독립 구분선, `글 N` 라벨, 반복되는 Markdown H1 순서로 글을 자동 분리한다.
- **REQ-003:** 분리 근거가 부족하면 원문을 단일 글로 보존하고 경고한다.
- **REQ-004:** H1 또는 첫 번째 유효 문장을 제목으로 추출한다.
- **REQ-005:** 특수 공백, 연속 공백, 줄 끝 공백, 과도한 빈 줄을 정규화한다.
- **REQ-006:** 제목, 강조, 목록, 인용, 링크, 코드, 표 등 핵심 Markdown을 안전한 HTML과 일반 텍스트로 변환한다.
- **REQ-007:** Markdown 표의 첫 행에 배경색·굵기·테두리·열 정렬을 인라인 스타일로 적용한다.
- **REQ-008:** 사용자는 표 제목행 색상을 선택할 수 있다.
- **REQ-009:** 글별 제목, 글자 수, 표 개수, 경고, 미리보기를 확인한다.
- **REQ-010:** 글마다 `안전 복사`와 `서식 복사`를 제공한다.
- **REQ-011:** 리치 클립보드가 불가능하면 일반 텍스트 복사로 자동 대체한다.
- **REQ-012:** 입력은 외부로 전송하거나 저장하지 않는다.
- **REQ-013:** 스크립트, 이벤트 속성, 위험한 URL과 임의 HTML을 실행하지 않는다.
- **REQ-014:** 원문은 변환 전까지 보존하고 초기화할 수 있다.
- **REQ-015:** 권장 범위인 3~5개를 벗어나도 처리하되 안내한다.
- **REQ-016:** 모바일과 데스크톱 모두에서 입력, 미리보기, 복사가 가능하다.
- **REQ-017:** 빈 입력과 100,000자 초과 입력을 명확히 차단한다.
- **REQ-018:** 기준 네이버 글의 `이 글에서 볼 내용`, 번호형 질문 소제목, `A:` 핵심 답변, 섹션 구분선을 자동 인식해 같은 시각 계층으로 변환한다.
- **REQ-019:** 표의 기본 제목행은 기준 글과 같은 `#F7F7F7` 회색 배경과 가운데 정렬을 사용하되, 명시적 Markdown 정렬은 보존한다.
- **REQ-020:** `────────────────────`처럼 문자로 그린 긴 구분선은 제거하고 서비스의 표준 구분선 한 개로 교체한다.
- **REQ-021:** 첫 글 앞의 GPT 작업 안내·작성 메모와 복사용 본문에 불필요한 참조형 인용 표시는 제거한다.

## 인수 기준

- **AC-001:** 구분선으로 연결한 3~5개 글은 같은 개수의 결과 카드로 표시된다.
- **AC-002:** 반복 H1 묶음은 각 H1을 제목으로 삼아 분리된다.
- **AC-003:** 모호한 입력은 내용 손실 없이 한 글로 유지되고 경고가 표시된다.
- **AC-004:** 연속 공백과 3개 이상의 빈 줄은 정리되지만 글자는 손실되지 않는다.
- **AC-005:** Markdown 표가 유효한 HTML 표로 변환되고 제목행 색상과 열 정렬이 반영된다.
- **AC-006:** 서식 복사는 `text/html`과 `text/plain`을 함께 제공한다.
- **AC-007:** Clipboard API가 거절되거나 없을 때 일반 텍스트 대체 복사가 동작한다.
- **AC-008:** 악성 HTML은 미리보기와 복사 결과에서 실행되지 않는다.
- **AC-009:** 글별 복사 결과에는 선택한 글만 포함된다.
- **AC-010:** 네트워크 호출이나 브라우저 저장소 기록 없이 동작한다.
- **AC-011:** 키보드만으로 핵심 흐름을 완료하고 상태 메시지를 확인할 수 있다.
- **AC-012:** 단위·통합·E2E 테스트, 린트, 타입 검사, 빌드가 통과하고 80% 이상 커버리지를 달성한다.
- **AC-013:** Chromium의 콘텐츠 편집 영역에 붙여넣었을 때 문단, 목록, 표 구조가 유지된다.
- **AC-014:** 네이버 SmartEditor 실제 붙여넣기는 발행 없이 수동 점검 항목으로 남기고, 완전한 서식 보존을 약속하지 않는다.
- **AC-015:** `이 글에서 볼 내용`은 16px 굵은 블록, 번호형 질문과 `A:` 답변은 15px 굵은 블록으로 출력된다.
- **AC-016:** 번호형 질문과 결론 질문 앞에는 한 개의 구분선이 생성되고, 입력의 중복 구분선은 추가로 출력되지 않는다.
- **AC-017:** 정렬 표시가 없는 표는 `#F7F7F7` 제목행과 가운데 정렬을 사용한다.
- **AC-018:** 문자·Markdown 구분선이 연속된 뒤 질문 소제목이 와도 표준 구분선은 중복되지 않으며, 문장 안의 짧은 선 문자는 보존된다.
- **AC-019:** 복붙·글 분할 작업 안내와 번호형 작성 메모는 첫 글 앞에서만 제거하고, 실제 미공개 정보 문장·일반 링크·코드 블록은 보존한다.

## 구현 작업

- **DEV-001:** 서비스 폴더와 개발 문서를 준비한다.
- **DEV-002:** 분리·정규화·Markdown 블록·표 직렬화 모델을 순수 함수로 작성한다.
- **DEV-003:** 글 분리, 콘텐츠 보존, XSS 방어 테스트를 먼저 작성한다.
- **DEV-004:** 안전 복사와 서식 복사 클립보드 어댑터를 구현한다.
- **DEV-005:** 입력, 요약, 결과 카드, 미리보기로 구성된 단일 화면을 구현한다.
- **DEV-006:** 표 제목행 색상 선택과 글별 복사 상태를 연결한다.
- **DEV-007:** WebMCP에 원고 변환 동작을 노출하고 미지원 환경에서는 조용히 비활성화한다.
- **DEV-008:** 반응형·접근성·오류·빈 상태를 다듬는다.
- **DEV-009:** 테스트, 린트, 타입 검사, 빌드, 보안 점검을 수행한다.
- **DEV-010:** 구현·검증·Cursor 인수인계 보고서를 작성한다.
- **DEV-011:** 공개된 기준 글의 실제 렌더링 스타일을 확인하고 질문·답변·목차·표 프리셋으로 반영한다.
- **DEV-012:** 긴 유니코드 구분선을 블록 단위로 인식해 표준 구분선으로 정규화한다.
- **DEV-013:** 코드 블록을 보호한 뒤 참조형 인용과 첫 글 앞의 고신뢰 생성 메타 문단을 정리한다.
- **DEV-014:** Markdown 링크를 단일 패스로 해석해 불완전한 링크 반복 입력도 선형 시간에 처리한다.

## 테스트 의무

- **TEST-001:** 구분선, `글 N`, 반복 H1 분리 규칙과 단일 글 폴백을 검증한다.
- **TEST-002:** 코드 블록·표 정렬행·하위 제목이 잘못된 분리를 만들지 않는지 검증한다.
- **TEST-003:** 한국어, 영문, 숫자, 이모지, 해시태그가 공백 정리 중 보존되는지 검증한다.
- **TEST-004:** 제목, 강조, 목록, 인용, 링크, 코드 변환을 검증한다.
- **TEST-005:** Markdown 표, 빈 셀, 열 정렬, 행 길이 불균형을 검증한다.
- **TEST-006:** 표 제목행 색상과 인라인 스타일 직렬화를 검증한다.
- **TEST-007:** 스크립트, 이벤트 속성, 위험한 URL이 실행 불가능한 텍스트로 처리되는지 검증한다.
- **TEST-008:** 클립보드 HTML·텍스트 페이로드와 권한 거절 폴백을 검증한다.
- **TEST-009:** 빈 입력, 최대 입력, 5개 초과 결과 안내를 검증한다.
- **TEST-010:** 입력→변환→글별 복사 핵심 흐름을 브라우저에서 검증한다.
- **TEST-011:** 390×844 화면에서 본문 가로 넘침이 없고 넓은 표만 내부 스크롤되는지 검증한다.
- **TEST-012:** 전체 테스트 커버리지 80%, 핵심 포매터 분기 커버리지 90% 이상을 확인한다.
- **TEST-013:** 기준 양식의 목차, 번호형 질문, `A:` 답변, 결론 질문, 구분선, 회색 표 제목행을 검증한다.
- **TEST-014:** 번호형 H2 앞의 `---`가 글 경계로 오인되지 않고 같은 글 안의 섹션 구분으로 유지되는지 검증한다.
- **TEST-015:** 긴 유니코드 구분선의 교체, 혼합·연속 구분선 병합, 질문 앞 중복 방지, 문장·코드 안 선 문자 보존을 검증한다.
- **TEST-016:** 작업 안내·작성 메모·참조 정의 제거와 실제 정보·일반 링크·인라인 및 펜스 코드 안 참조 문법 보존을 검증한다.
- **TEST-017:** 최대 길이에 가까운 불완전한 Markdown 링크 반복 입력이 1초 이내에 렌더링되는지 검증한다.

## 주요 위험과 대응

- 네이버가 외부 HTML/CSS를 자체 정리할 수 있다. 안전 복사를 기본 경로로 함께 제공하고 서식 복사를 실험 기능으로 명시한다.
- `---`는 본문 구분선일 수 있다. 분리 결과를 반드시 먼저 보여주며 원문을 자동 삭제하지 않는다.
- 한국어 문법 수준의 띄어쓰기는 로컬 규칙만으로 정확히 고칠 수 없다. 중복·특수 공백과 문단만 정리한다.
- 이미지는 복사 대상에 포함하지 않는다. 네이버 포토 업로더로 별도 등록하도록 안내한다.
