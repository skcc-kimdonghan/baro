# 바로발행

GPT에서 작성한 3~5개 블로그 원고를 한 번에 붙여넣고, 글별로 분리해 네이버 블로그에 옮기기 좋은 최종 원고로 정리하는 브라우저 도구입니다.

## 주요 기능

- `---`, `글 N`, 반복 H1 기준 자동 분리
- 연속 공백·과도한 빈 줄·Markdown 기호 정리
- 제목, 문단, 목록, 인용, 링크, 코드, Markdown 표 변환
- 표 제목행 색상과 열 정렬 적용
- 기준 글의 목차, 번호형 질문 소제목, `A:` 답변, 섹션 구분선 자동 스타일링
- `────────────────────` 같은 잘못된 문자 구분선을 표준 구분선으로 자동 교체
- GPT의 복붙 안내·작성 메모·참조형 인용 표시를 최종 본문에서 자동 제거
- 제목 뒤 첫 질문 줄을 기울임꼴로 적용
- 이미지 생성 프롬프트를 본문에서 분리해 `아래 이미지를 생성해주세요` 블록으로 별도 복사
- 놀이기구 글 하단에 에버랜드 우리아이 놀이기구 찾기 링크 자동 추가
- 글별 `발행 완료` 체크와 실제 네이버 발행 본문 붙여넣기
- 제공 원고 대비 누락·추가·순서·문단·놀이기구 링크 차이와 일치도 표시
- 기준 표 스타일인 회색 제목행(`#F7F7F7`)과 가운데 정렬을 기본 적용
- 글별 제목 복사, 본문 안전 복사, 본문 서식 복사
- 입력을 서버나 브라우저 저장소에 남기지 않는 로컬 처리
- 실제 발행 본문 비교도 현재 탭의 메모리에서만 처리
- 리치 클립보드 실패 시 일반 텍스트 자동 대체

네이버 SmartEditor는 외부 HTML/CSS를 자체적으로 정리할 수 있으므로, `본문 서식 복사`의 색상과 간격은 편집기 상태에 따라 달라질 수 있습니다. 이미지는 네이버 포토 업로더로 별도 등록해야 합니다.

## 실행

```bash
npm ci
npm run dev
```

로컬 주소는 기본적으로 `http://localhost:5173`입니다.

## 검증

```bash
npm run test:coverage
npx tsc --noEmit
npm run lint
npm run build
```

기획과 검증 기록은 `docs/development/`에 있습니다.
